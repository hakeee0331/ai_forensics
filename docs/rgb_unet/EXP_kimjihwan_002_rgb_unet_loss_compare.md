## 목적·가설

RGB 입력 ResNet-50 U-Net을 AutoSplice train 전체로 학습해 세 U-Net 비교의 기준 성능을 얻음. 같은 조건에서 손실 함수만 바꾼 세 조건을 비교하고, val 조작 이미지 평균 F1이 가장 높은 손실을 이후 ELA·RGB+ELA U-Net에 사용함.

| 조건 | 손실 |
| --- | --- |
| `bce` | BCEWithLogits |
| `dice` | 이미지별 soft Dice의 평균(ε=1) |
| `bce_dice` | BCEWithLogits + 이미지별 soft Dice 평균, 1:1 |

001에서 바꾼 조건은 학습 데이터(train 조작 전체), 학습량(최대 30 epoch·조기 종료), 손실 비교, 평가 패딩(공통 함수 `pad_image`·`unpad_image`), 테스트 범위(004와 동일)임.

T06 중 ELA 설정·전처리 순서·256 크롭·평가 패딩은 팀 합의로 확정됨([전처리 안내](../preprocessing.md)). RGB 모델이라 ELA는 쓰지 않음. 손실·학습 조건·임계값·집계는 미확정이며, 이 실험의 손실 비교는 그 논의의 근거로 사용함.

## 분석 — 2026-11-24

아래는 저장 출력에 대한 해석이며 팀 합의가 아님.

**손실 함수.** 세 조건의 val F1 차이는 최대 0.0026, test JPEG100 F1 차이는 최대 0.0008로 매우 작음. 같은 시드 한 번씩의 결과라 이 차이가 손실의 효과인지 학습의 무작위성인지 구분할 수 없음. 이 데이터·모델에서는 손실 선택이 성능을 좌우하지 않는다고 봄. `bce_dice`는 가장 적은 epoch(최고 14)로 수렴했고, `dice` 단독은 초반 val 정상 오탐률이 크게 흔들려 상대적으로 불안정했음. JPEG90에서는 `dice`(0.177)가 다른 둘(0.276·0.279)보다 낮았으나 세 조건 모두 JPEG100과 비교하면 크게 무너진 상태임.

**압축 조건에 따른 붕괴.** 같은 모델이 AutoSplice JPEG100에서는 F1 0.968이지만, 같은 이미지를 JPEG90으로 다시 저장하면 0.18~0.28, JPEG75면 0.005~0.007로 떨어짐. CocoGlide에서는 정상 이미지의 97~98% 픽셀을 조작으로 표시했고, 조작 이미지의 F1 0.36은 위치를 맞힌 결과가 아니라 이미지 대부분을 칠한 결과로 보임(7절 그림).

**해석: 압축 이력 단서에 의존한 것으로 보임.** AutoSplice 조작본의 마스크 밖은 Q75 원본을 Q100으로 다시 저장한 영역(두 번 압축)이고, 마스크 안은 생성 모델이 새로 만든 픽셀을 Q100으로 저장한 영역(한 번 압축)임. 결과는 모델이 내용보다 이 픽셀 단위 압축 이력 차이로 경계를 그었다는 가설과 맞음.

| 관찰 | 가설에 따른 설명 |
| --- | --- |
| JPEG100 F1 0.97 | 학습과 같은 압축 조건이라 두 영역의 차이가 그대로 남음 |
| JPEG90·75 F1 급락 | 이미지 전체를 다시 압축하면 마스크 안도 두 번 압축되어 차이가 줄어듦 |
| AutoSplice 정상 오탐률 거의 0 | 정상 원본에는 Q75 흔적만 있어 조작으로 보지 않음 |
| CocoGlide 정상 오탐률 0.97 | PNG를 JPEG100으로 한 번 저장해 이미지 전체가 "한 번 압축"에 가까운 상태가 됨. CocoGlide는 COCO JPEG 사진에서 만들어졌을 것으로 보이나 256×256으로 줄이며 예전 블록 흔적이 흐트러졌을 것으로 추정함 |

정상 이미지를 학습에서 빼서 파일 단위 지름길(정상 Q75 / 조작 Q100)은 막았지만, 같은 조작 이미지 안의 영역별 압축 이력 차이는 남아 있었던 것으로 보임. 이 가설은 결과 패턴과 그림에 근거한 추론이며, 압축 이력을 통제한 비교 실험(예: 학습 중 JPEG 재압축)으로 확인해야 함. CAT-Net도 JPEG 압축 흔적을 쓰는 모델이지만 JPEG90에서 0.80을 유지해, 이 U-Net보다 재압축에 훨씬 강했음.

**제안서 목표와의 관계.** 목표 Pixel F1 0.75는 AutoSplice JPEG100에서만 넘었고 JPEG90·75·CocoGlide에서는 크게 못 미침.
