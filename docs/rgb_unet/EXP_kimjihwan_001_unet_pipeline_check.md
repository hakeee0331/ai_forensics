## 목적

세 U-Net(RGB·ELA·RGB+ELA)이 같은 코드로 데이터 구성, 학습, 체크포인트 저장·재로드, 원본 해상도 추론, 공통 평가 함수 계산까지 이어지는지 확인함. [패키지 사용 제안](../package_proposal.md)의 T03 검증 항목을 그대로 따름.

1. torch·torchvision import와 ImageNet 사전학습 ResNet-50 가중치 로드.
2. 3채널·6채널 입력의 예측 크기·채널·자료형.
3. 작은 학습 배치의 순전파·역전파·최적화와 검증 단계.
4. 체크포인트 저장·재로드 후 예측 일치.
5. 원본 해상도 추론 결과를 공통 평가 함수에 연결.

기본 비교 실험(T09~T11)이 아님. 학습 조건을 비교하거나 성능 가설을 검증하지 않음.

## 모델·학습 설정 — 동작 확인용 임시값

아래 값은 노트북을 돌리기 위한 임시값이며 T06의 팀 합의가 아님. 크롭 크기와 ELA 후보는 [전처리 실데이터 검증](../eda/EXP_byhyun_001_preprocessing_check.md)의 제안을 따름.

| 항목 | 값 |
| --- | --- |
| 인코더 | torchvision ResNet-50, `IMAGENET1K_V2` |
| 디코더 | conv1·layer1~4 특징을 잇는 5단 U-Net 디코더(256→128→64→32→16), 최근접 업샘플링, 1×1 출력 |
| 입력 | `rgb` 3채널, `ela` 3채널, `rgb_ela` 6채널(RGB 다음 ELA) |
| 6채널 conv1 | RGB 가중치를 ELA 채널에 그대로 복사. 크기 조정 없음 |
| ELA 3채널 conv1 | RGB용 사전학습 가중치를 그대로 사용 |
| 입력 정규화 | RGB·ELA 모두 0~1 변환 후 ImageNet 평균·표준편차 |
| 크롭 | 256×256, 시작 좌표는 16의 배수 |
| ELA | quality 90, scale 15, subsampling 2(4:2:0). 크롭 후 계산 |
| 반전 | 확률 0.5, RGB·ELA·마스크에 같은 좌우반전 |
| 손실 | BCEWithLogits + soft Dice, 1:1 |
| 최적화 | Adam, 학습률 1e-4 |
| 배치 | 4 |
| 학습량 | RGB는 같은 배치 30 step(과적합 확인), ELA·RGB+ELA는 2 step |
| 시드 | 42 |
| 체크포인트 | `/content/checkpoints`에 임시 저장. Drive·Git에는 저장하지 않음 |

## 평가 설정 — 연결 확인용

몇 step만 학습한 모델의 값이며 모델 성능이나 입력 구성 간 비교로 해석하지 않음.

| 모델 | 조작 이미지 평균 F1 | 조작 이미지 평균 IoU | 정상 이미지 평균 오탐률 |
| --- | ---: | ---: | ---: |
| rgb | 0.138138 | 0.074751 | 0.232818 |
| ela | 0.186738 | 0.112475 | 1.000000 |
| rgb_ela | 0.000000 | 0.000000 | 0.000000 |

ela 모델은 검증 8장의 모든 픽셀을 조작으로 예측했고(FN·TN 0), rgb_ela 모델은 모든 픽셀을 정상으로 예측함(TP·FP 0). 2 step만 학습한 모델의 출력이 임계값 한쪽으로 쏠린 결과이며 파이프라인 오류로 보지 않음. 이미지별 TP·FP·FN·TN 표는 노트북 7절 출력에 있음.
