## 목적·가설

제안서 4-3대로 val F1이 가장 높았던 RGB+ELA 입력에 JPEG 품질 증강(70~100)을 넣고, 004와 같은 학습 예산으로 학습해 품질별 하락 폭이 줄어드는지 확인함. 004는 JPEG100 F1 0.972에서 JPEG90·75 F1 0.005·0.008로 무너졌음.

004에서 바꾼 학습 조건은 JPEG 증강 하나뿐임. 모델 선택 기준과 평가 범위를 아래처럼 넓힘.

## 데이터

004와 같음. 학습 AutoSplice train 조작 2,925장(JPEG100, 정상 제외), 검증 val 조작 361장을 JPEG 100·90·75에서 각각, val 정상 227장. 테스트 AutoSplice test 조작 JPEG 100·90·75 각 335장과 정상 228장, CocoGlide 정상·조작 각 512장을 PNG에서 JPEG **100·90·75**(4:4:4)로 변환한 입력. 테스트 합계 4,305장.

## 분석

아래는 저장 출력에 대한 해석이며 팀 합의가 아님. 시드 1회 실행임.

**제안서 4-3의 질문에는 분명한 답이 나옴.** 같은 학습 예산에서 JPEG 증강은 AutoSplice의 품질별 하락을 거의 없앰(JPEG75 하락 −0.96 → −0.12). 대가로 JPEG100 F1이 0.058 낮아짐.

**JPEG75 회복의 단서는 여전히 압축 이력일 수 있음.** 006에서 JPEG75는 Q75 정렬도의 안·밖 차이가 사라졌지만 ELA 차이는 남았음(ELA AUC 0.72). 마스크 밖은 Q75 원본을 Q100을 거쳐 다시 Q75로 저장한 같은 품질 이중 압축이고, 안은 Q75 첫 압축임. 005는 학습 중 q≈75 재저장 샘플을 봤으므로 이 단서를 배웠을 수 있음. 생성 영역의 질감 차이와는 이 실험으로 구분하지 못함.

**004의 단서는 압축 상태에 직접 묶여 있었음.** 004는 AutoSplice JPEG90·75에서 픽셀 AUC가 0.33으로 0.5보다 낮아, 신호 방향이 뒤집혔음.

**정상 이미지 과탐지가 새로 생김.** AutoSplice 정상 오탐률이 0.001에서 0.323으로 올랐고 val에서도 학습이 진행될수록 증가함. 조작 이미지만 학습해 조작이 없는 이미지를 본 적이 없기 때문으로 보임(007에서 확인).

**CocoGlide는 여전히 위치를 찾지 못함.** JPEG100에서 픽셀 AUC 0.53, 쌍 차이 AUC 0.47로 위치 정보가 없고 F1은 기준선 수준임. 이미지 전체가 재압축된 JPEG90·75에서만 약한 신호가 나옴(쌍 차이 AUC 0.55~0.59, 이득 +0.07~0.16). 004와 005의 CocoGlide 차이는 주로 칠하는 양의 차이임.

**선택 기준의 영향이 큼.** 두 기준의 epoch가 달랐고(10 대 6), JPEG90 F1이 0.70~0.79, 정상 오탐률이 0.17~0.32로 달라짐.
