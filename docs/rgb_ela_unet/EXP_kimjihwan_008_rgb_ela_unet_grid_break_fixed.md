## 목적·가설

007은 압축 격자 깨기를 의도했지만 짧은 변 256 이미지(학습 이미지의 90% 이상)에서 적용되지 않았음. 008은 격자 깨기를 실제로 적용하고 나머지는 007과 같게 두어, **격자 깨기만의 효과**를 007과 비교함.

가설: 학습 중 압축 격자를 깨서 "압축 흔적 유무" 지름길을 끄면, CocoGlide JPEG100에서 이미지 전체 칠하기가 줄고 위치 정보가 생김.

**성공 기준(실행 전 고정, 007과 같음):** CocoGlide JPEG100에서 (1) 정상 오탐률이 007(0.922)보다 확실히 낮고, (2) 픽셀 AUC와 쌍 차이 AUC가 0.5를 확실히 넘음(007: 0.636, 0.514).

이 실험은 제안서에 없는 추가 실험이며 CocoGlide 테스트 결과를 보고 설계한 **탐색적 실험**임. 모델 선택은 AutoSplice val로만 함.

## 분석

아래는 저장 출력에 대한 해석이며 팀 합의가 아님. 시드 1회 실행임.

**성공 기준을 모두 넘음.** 007과 다른 조건은 격자 깨기뿐이며, CocoGlide JPEG100에서 정상 오탐률이 0.922 → 0.527로 줄고, 픽셀 AUC 0.636 → 0.749, 장면 내용을 뺀 쌍 차이 AUC 0.514 → 0.604로 올랐음. F1이 처음으로 전부 조작 기준선(0.355)과 섞은 마스크 F1(0.309)을 확실히 넘었음(섞기 대비 이득 +0.017 → +0.106). 압축 흔적이 없는 CocoGlide에서 조작 자체를 가리키는 신호를 배웠다고 볼 수 있음.

**지름길의 대가가 확인됨.** AutoSplice JPEG100 F1이 007의 0.933에서 0.835로 낮아졌음. 006에서 측정한 압축 흔적 지름길을 빼앗자 그만큼 떨어진 것으로 해석함. 대신 품질별 하락 폭은 가장 작아짐. AutoSplice 정상 오탐률은 0.051에서 0.120으로 올랐음.

**단계별 흐름.**

| 실험 | 바꾼 것 | 해결한 것 | 남은 문제 |
| --- | --- | --- | --- |
| 004 | 기준 | AutoSplice JPEG100 F1 0.972 | 재압축 붕괴, CocoGlide 전체 칠하기 |
| 005 | + JPEG 품질 증강 | 재압축 붕괴(JPEG75 F1 0.008 → 0.794) | AutoSplice 정상 과탐지(0.323), CocoGlide 그대로 |
| 007 | + 정상 이미지 | AutoSplice 정상 과탐지(0.051) | CocoGlide 그대로(오탐률 0.922) |
| 008 | + 압축 격자 깨기 | CocoGlide 과탐지 감소(0.527), 위치 정보 생김(쌍 차이 AUC 0.604) | AutoSplice JPEG100 하락(0.835) |

**CAT-Net과 비교.** 같은 CocoGlide JPEG100 조건의 사전학습 CAT-Net([kimjaehak 004](../catnet/EXP_kimjaehak_004_catnet_pretrained_evaluation.md))은 F1 0.363874, 정상 오탐률 0.166143임. 008은 F1이 높고 정상 오탐률이 높음. 학습 데이터와 목적이 달라 우열을 정하지 않음.

## 결론

AutoSplice로 학습한 U-Net의 CocoGlide 과탐지는 JPEG 압축 흔적에 의존한 지름길 때문이었던 것으로 보임. 학습 중 압축 격자를 깨자(나머지 조건 동일) CocoGlide 정상 오탐률이 0.92에서 0.53으로 줄고 장면 내용을 뺀 위치 신호(쌍 차이 AUC 0.60)가 생겼으며, 대가로 AutoSplice JPEG100 F1은 0.93에서 0.83으로 낮아졌음. 다른 시드에서의 재현과 학습 설정 조정은 확인하지 않은 탐색적 결과임.
