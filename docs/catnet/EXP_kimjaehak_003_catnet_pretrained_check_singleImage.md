## 목적과 범위

공식 CAT-Net v2 구조에 배포된 전체 가중치를 적용하고, Colab의 현재 패키지 조합에서 실제 JPEG 한 장의 입력 구성과 GPU 추론이 가능한지 확인함. 학습·파인튜닝은 수행하지 않음. AutoSplice train 한 장의 점수는 동작 확인 결과이며 테스트 성능이나 데이터셋 평균이 아님. 전체 평가는 후속 실험으로 남김.

## 모델·가중치·입력

- 공식 저장소: [mjkwon2021/CAT-Net](https://github.com/mjkwon2021/CAT-Net). 출력된 커밋 ID: `5eb85900b0e72423c95a8d41bc835b86c8671f8a`.
- `experiments/CAT_full.yaml`을 기본 설정에 병합하고 `network_CAT.CAT_Net(cfg)`로 구조를 생성함. 출력 클래스 2개, 파라미터 114,263,810개임.
- 실제 저장 코드의 로드 옵션은 `torch.load(..., map_location="cpu", weights_only=False)`임. 체크포인트 항목은 epoch·best_p_mIoU·state_dict·optimizer이며 epoch은 196임. optimizer는 복원하거나 학습에 사용하지 않음.
- `state_dict`를 `strict=True`로 적용했으며 누락된 키와 예상하지 않은 키는 모두 빈 목록임. 모델을 cuda:0으로 이동하고 eval 모드를 확인함.

## 저장 출력 검토

전체 30셀 중 코드 셀은 21개이며 모두 출력이 있음. 저장된 오류 출력은 0개, PNG 그림은 2개임. 실행번호는 8~39 사이에 공백이 있고, 가중치 읽기 셀은 출력이 있지만 execution_count가 null임. 모델 적용·추론·지표 출력으로 단일 이미지 동작은 확인했으나, 깨끗한 커널에서 위에서부터 일괄 실행한 결과인지는 확인할 수 없음. 실행 시각은 셀 메타데이터에 기록되지 않음.

## 정성 검토와 해석 — 2026-11-20

검토자: Codex. 근거: 저장된 23·27셀 그림 및 29셀 수치.

예측은 정답의 중앙 조작 영역 대부분을 포함하고, 일부 경계를 정답보다 넓게 표시함. 정답 조작 픽셀 8,121개 중 8,105개를 검출하고 16개를 놓쳤으며, 마스크 밖 1,659개 픽셀을 조작으로 예측함. 한 표본에서의 위치 대응과 과검출 사례를 확인한 것이며 다른 이미지로 일반화하지 않음.

노트북 마지막 메모는 마스크 밖에도 실제 조작이 있었을 가능성을 제시함. 이는 추가 검토할 가설임. 현재 그림과 점수만으로 마스크 오류나 조작 범위 확장을 확정할 수 없으며, 모델의 경계 오차나 출력 보간의 영향도 구분되지 않음. 정답을 검증·정정하기 전까지 FP 1,659개는 현재 마스크 기준 오탐으로 유지함.

메모의 TP·FN을 줄여 평가한다는 표현은 수정 해석이 필요함. 정답을 고정하면 TP는 높이고 FN·FP는 낮추는 방향이 바람직함. 이번 검토에서는 기존 노트북 메모와 측정값을 보존하고, 보고서에 해석만 추가함. 평가 지표나 임계값을 이 표본에 맞춰 변경하지 않음.
