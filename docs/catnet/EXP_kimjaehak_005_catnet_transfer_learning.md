## 목적·가설

동일한 CAT_full_v2에서 시작해 학습 범위가 내부 검증·테스트와 외부 일반화에 미치는 영향을 확인함. 005는 last_layer만, 006은 전체 파라미터를 학습함. 006은 005 결과에서 이어 학습하지 않음. 정상 픽셀 오탐률을 조작 F1·IoU와 함께 평가함.

## 실제 모델·데이터·학습 설정

## 정성 검토·해석 — 2026-11-22, Codex

학습 크롭 1개와 테스트 그림 12개를 확인함. 크롭의 마스크 오버레이는 표시된 영역과 겹침. 이는 저장 그림의 검토이며 데이터셋 전체 정답의 적절성에 대한 팀원 승인이 아님. 테스트 그림은 6집단에서 seed 42로 각 2장을 선택했으며 최초 평가의 혼동행렬과 일치 검사를 통과함.

- JPEG100 `41619_2.jpg`·`48344_1.jpg`: 인물·간판 영역의 위치를 대체로 검출함. F1은 각각 0.9565·0.9402이며 경계와 내부 일부 누락이 보임.
- JPEG75 `43680_0.jpg`·`40740_0.jpg`: 두 예측 마스크 모두 비어 있고 F1=0임. 전체 JPEG75 335장 중 286장에서 예측 양성이 없으며 287장에서 TP=0임.
- JPEG90 `54827_1.jpg`는 부분 누락(F1=0.8075), `60785_1.jpg`는 작은 부분만 검출(F1=0.0237)함.
- 정상 AutoSplice `53693.jpg`·`47509.jpg`: 둘 다 FPR=0임. 정상 228장 중 221장은 오탐 픽셀이 없음.
- CocoGlide `glide_inpainting_val2017_532129_up.png`: 피자 조작 영역 대부분을 검출하지만 배경까지 넓게 예측함. F1=0.8309만으로 경계 검출이 좋다고 판단하기 어려움. `glide_inpainting_val2017_78959_up.png`도 정답 밖에 넓은 과검출이 보이며 F1=0.1988임.
- 정상 CocoGlide `toothbrush_365385.png`·`laptop_11813.png`: 넓은 배경과 물체를 조작으로 예측하며 FPR=0.5697·0.7696임. 정상 512장 모두에서 오탐이 발생했고 이미지별 평균 오탐 픽셀 비율은 80.7781%임. 이는 이미지 단위 오탐률 80.7781%라는 뜻이 아님.

004 대비 AutoSplice JPEG100 F1은 0.881532→0.927879로 개선됐으나 JPEG90은 0.804874→0.492831, JPEG75는 0.402828→0.018991로 하락함. CocoGlide F1도 0.363874→0.326771로 하락하고 정상 픽셀 오탐률은 0.166143→0.807781로 증가함. CocoGlide 조작 이미지의 평균 예측 면적도 전체의 77.3001%로 넓음.

학습 데이터의 정상·조작 JPEG 이력 차이를 검출 단서로 학습했을 가능성이 있음. JPEG100에서 개선되고 JPEG75에서 대부분 놓치며 JPEG100으로 변환한 정상 CocoGlide를 과검출하는 패턴이 이 가설과 부합함. 원인 확정은 아니며 데이터 도메인·장면·변환 영향도 분리하지 못함. 학습 데이터 내부 개선과 압축 강건성·외부 일반화의 악화를 함께 기록함.

## 검증 범위·후속 작업

코드 셀 15개, 실행번호 4~18, 오류 출력 0개, PNG 13개를 확인함. 실행번호만으로 깨끗한 커널에서 시작했다고 단정하지 않음. 공식 코드의 `F.upsample` 폐기 예정 경고와 배열 목록의 텐서 변환 성능 경고가 있으나 예외는 발생하지 않음. 이 경고가 성능 저하의 원인이라고 단정하지 않음.

노트북 첫 상태와 마지막 사람 검토 메모에는 준비 시 문구가 남아 있음. 저장된 원본을 수정하지 않고 실제 실행 상태는 이 보고서와 TODO에 기록함. 팀원의 마스크·예측 검토 확인은 아직 없음. 사전학습 데이터 중복 가능성, 정상·조작 JPEG 이력 차이, PNG 변환의 한계와 T03·T05·T06·T19의 최종 합의는 남아 있음.

후속 실험에서는 압축 이력에 대한 의존 여부를 train·val에서 점검해야 함. JPEG100의 개선만으로 전체 모델을 대체하지 않음. 테스트 결과를 보고 임계값·학습률을 고르지 않으며 재실험은 새 개인 번호를 사용함. 공통 스크립트와 실행된 005·006은 변경하지 않음.
