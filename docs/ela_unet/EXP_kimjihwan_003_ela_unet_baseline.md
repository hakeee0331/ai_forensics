## 목적·가설

ELA 3채널 입력 ResNet-50 U-Net을 002의 RGB U-Net과 같은 조건으로 학습해 입력 구성의 효과를 비교함. 002의 RGB U-Net은 AutoSplice JPEG100에서 높았으나 JPEG90·75와 CocoGlide에서 크게 떨어져 압축 이력에 의존한 것으로 보였음. ELA는 압축 오차를 직접 입력으로 쓰므로 검출에 도움이 되는지, 같은 경향이 더 강하게 나타나는지 확인함.

002에서 바꾼 조건은 입력(RGB → ELA)과 손실(세 조건 비교 → 002에서 val로 선택된 `bce_dice` 한 조건)뿐임. 비교 대상은 002의 `bce_dice` 조건임.

## 데이터

002와 같음. 학습은 AutoSplice train 조작 2,925장(JPEG 100, 정상 제외), 검증은 val 조작 361장·정상 227장, 테스트는 AutoSplice test JPEG 100·90·75 조작 각 335장과 정상 228장, CocoGlide 정상·조작 각 512장(PNG→JPEG100·4:4:4)으로 합계 2,257장임. 3절의 첫 배치 마스크 비율 16개가 002와 같아, 같은 시드에서 같은 표본·크롭 위치가 뽑혔음을 확인함.

## 모델·학습

| 항목 | 값 |
| --- | --- |
| 모델 | ResNet-50(IMAGENET1K_V2) 인코더 U-Net, 002와 같은 구조. conv1은 RGB 사전학습 가중치를 그대로 사용. 파라미터 32,520,977개 |
| 입력 | ELA 3채널. 0~1 변환 후 ImageNet 평균·표준편차 정규화(T06 미확정, 001과 같은 선택) |
| ELA | quality 90, scale 15, subsampling 2. 팀 확정 규약 |
| 처리 순서 | 원본 전체에서 ELA 계산 → ELA·마스크를 같은 위치 256×256 크롭(좌표 16의 배수) → 확률 0.5 같은 좌우반전. 팀 확정 규약 |
| 손실 | BCEWithLogits + 이미지별 soft Dice 평균(ε=1), 1:1 |
| 최적화·학습량 | Adam 1e-4 고정, 배치 16(epoch당 182 step), 시드 42, 최대 30 epoch, val 조작 평균 F1 기준 patience 5 |
| JPEG 증강 | 미사용. 002와 조건을 맞추기 위함 |

## 분석 — 2026-11-24

아래는 저장 출력에 대한 해석이며 팀 합의가 아님. 두 실험 모두 시드 1회 실행임.

**같은 압축 조건에서는 ELA가 약간 낮음.** val F1(0.952 대 0.964), JPEG100 test F1(0.957 대 0.969), AutoSplice 정상 오탐률(0.0125 대 0.0006) 모두 RGB U-Net이 나았음. 학습 곡선도 ELA 쪽이 더 흔들렸음. 이 조건에서 "ELA가 압축 오차를 직접 보여 주므로 검출에 도움이 된다"는 가설은 지지되지 않음.

**재압축과 외부 데이터에서는 두 입력 모두 무너짐.** JPEG75에서는 둘 다 F1 0.01 미만이고, CocoGlide에서는 둘 다 정상 픽셀의 94~97%를 조작으로 표시했으며 조작 F1 0.36은 이미지 대부분을 칠한 결과로 보임(7절 그림). 002에서 세운 가설, 즉 모델이 내용보다 영역별 압축 이력 차이(마스크 밖은 Q75→Q100 두 번 압축, 마스크 안은 Q100 한 번 압축)로 경계를 긋는다는 해석이 ELA 입력에도 그대로 들어맞음. 7절 그림에서 같은 JPEG100 조작 이미지를 마스크와 거의 같게 칠하면서, 한 번만 압축된 CocoGlide 이미지는 전체를 칠한 점이 이를 보여 줌.

**JPEG90에서 ELA가 특히 나쁜 이유(추정).** ELA를 quality 90으로 계산하므로, 이미 Q90으로 저장된 이미지를 다시 Q90으로 압축하면 변화가 거의 없어 ELA가 이미지 전체에서 0에 가까워질 수 있음. 그러면 모델이 쓸 신호 자체가 사라짐(F1 0.001). [byhyun 001](../eda/EXP_byhyun_001_preprocessing_check.md)에서 Q75 정상 원본의 ELA(75, 4:2:0)가 거의 0이었던 것과 같은 원리로 봄. 이 실행에서는 JPEG90 입력의 ELA 크기를 직접 측정하지 않았으므로 확인이 필요함. RGB U-Net은 JPEG90에서 0.28이 남아, ELA는 "ELA 품질과 입력 JPEG 품질이 같으면 아무것도 보이지 않는다"는 약점이 더 직접적으로 드러남.

**비용.** ELA를 매 샘플 원본 전체에서 계산해 epoch당 학습이 약 6초, 검증이 약 5초 늘었음(002 대비).

## 결론과 후속 작업

- 현재 조건(JPEG100 학습, 증강 없음)에서 ELA 입력은 RGB 입력보다 나은 점이 없음. 같은 압축 조건에서는 약간 낮고, 재압축·외부 데이터에서는 RGB와 함께 무너지며, JPEG90에서는 더 나빴음.
- 두 입력 모두 압축 이력 단서에 의존한 것으로 보이므로, JPEG 증강(T14)을 앞당겨 두 입력을 다시 비교할 필요가 있음. ELA는 증강 후 재압축된 크롭에서 다시 계산해야 함(제안서 계획).
- JPEG90 입력의 ELA 크기를 측정해 "ELA 품질과 입력 품질이 같으면 신호가 사라진다"는 추정을 확인함.
- RGB+ELA U-Net(T11)은 같은 조건으로 진행하거나, 증강 조건이 정해진 뒤 진행할지 팀과 정함.
