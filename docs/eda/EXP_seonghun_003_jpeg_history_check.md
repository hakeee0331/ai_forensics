## 요약

- AutoSplice 정상 원본 2,273장은 **모두 JPEG 품질 75**, `Forged_JPEG100` 조작본 3,621장은 **모두 품질 100**으로 저장돼 있음. train·val·test 모두 같음.
- `Forged_JPEG90`·`Forged_JPEG75` 조작본은 모두 폴더 이름의 품질(90·75)로 저장돼 있음. 모든 AutoSplice 파일이 4:2:0·표준 양자화 테이블이며 예외는 0개임.
- CocoGlide 정상·조작 1,024장은 모두 PNG로 JPEG 저장 이력이 없음.
- 따라서 JPEG100 조작본과 정상 원본은 **저장 품질만으로 100% 구분됨.** 모델이 조작 흔적 대신 이 차이를 지름길로 쓸 수 있어 학습·평가 조건을 팀이 논의해야 함.

## 목적

byhyun 001은 train 표본 200장에서 정상 원본이 모두 Q75·4:2:0, 조작본(JPEG100 폴더)이 모두 Q100·4:2:0인 것을 확인하고, 같은 차이가 전체 split과 CocoGlide에서도 나타나는지 T05에서 확인하도록 남김. 이번 작업은 전체 파일에서 이를 확인함.

이미지 픽셀은 디코드하지 않음. JPEG 파일은 압축에 쓴 양자화 테이블을 헤더에 저장하므로, 표준(IJG) 테이블을 쓰는 인코더로 저장된 파일은 테이블만으로 저장 품질을 정확히 알 수 있음.

작성 단계에서 로컬 합성 데이터로 실행해, 일부러 품질 88·4:4:4로 바꿔 저장한 조작본 1장이 기대 조건과 다른 파일로 표시되는 것을 확인함. 합성 데이터 결과는 실제 결과에 포함하지 않음.

## 분석

### 저장 품질이 지름길이 될 수 있음

정상 원본은 모두 Q75, JPEG100 조작본은 모두 Q100이므로 두 집합은 저장 품질만으로 완전히 구분됨. 품질 차이는 8×8 블록 경계와 고주파 성분의 양자화 흔적으로 픽셀에 남기 때문에, RGB 입력 모델도 학습 과정에서 이 차이를 쓸 수 있음. 실제로 모델이 이 단서를 쓰는지는 확인하지 않음.

- **조작 위치 찾기:** 조작본 안에서는 조작 영역과 나머지 영역이 같은 Q100으로 저장돼 있어, 저장 품질만으로 조작 위치를 알 수는 없음.
- **정상 이미지 판단:** 모델이 "Q75로 저장된 이미지는 정상이므로 아무것도 표시하지 않는다"는 단서를 쓸 수 있음. 이 경우 정상 이미지의 픽셀 오탐률이 실제 능력보다 좋게 나올 수 있음. test에서도 같은 차이가 유지되므로 평가 점수에 그대로 반영됨.
- **JPEG75 폴더:** 조작본도 정상과 같은 Q75라 저장 품질 단서가 사라짐. 같은 모델의 품질별 점수 차이에는 이 효과가 포함될 수 있음.
- **ELA:** byhyun 001에서 ELA 설정 (75, 2)의 정상 원본 ELA가 거의 0이었던 이유가 이 저장 이력이며, 이번 결과로 전체 데이터에서 같은 조건임이 확인됨.
- **CocoGlide:** 정상·조작 모두 PNG라 이 단서가 없음. AutoSplice와 CocoGlide의 점수 차이를 해석할 때 고려해야 함. CAT-Net 004는 CocoGlide PNG를 JPEG100·4:4:4로 변환해 평가했음.

### 팀 논의가 필요한 선택지

아래는 결정이 아니라 논의할 선택지임. 테스트 데이터 결과로 선택하지 않음.

1. 학습용 조작본 폴더 선택: 정상과 같은 Q75인 `Forged_JPEG75`를 쓰거나 세 품질을 섞어 쓰는 방법.
2. 정상·조작의 압축 조건을 맞추는 재압축 또는 JPEG 증강(T14)을 기본 비교에 포함할지 여부.
3. 평가를 JPEG 품질별로 나눠 보고하고, 정상 오탐률 해석에 저장 품질 차이를 한계로 명시하는 방법.

## 결론과 한계

byhyun 001이 표본에서 확인한 저장 품질 차이(정상 Q75, JPEG100 조작본 Q100)가 AutoSplice 전체 split에서 예외 없이 같음을 확인함. 조작본 폴더의 품질 표기도 실제 저장 품질과 모두 일치함. 이 차이가 학습·평가에 미치는 영향은 T06·T14와 함께 팀이 정해야 함.

- 저장 품질만 확인했으며, 조작본이 저장되기 전에 몇 번 압축됐는지(이중 압축 여부)는 확인하지 않음.
- 모델이 실제로 저장 품질 단서를 쓰는지는 학습 실험으로 확인해야 함.
- CocoGlide PNG가 PNG로 저장되기 전에 JPEG였는지는 헤더로 알 수 없음.
- 노트북 6절의 사람 검토 메모는 채워지지 않았으며 판단 내용은 이 보고서에 기록함.
