## 목적과 확인할 사항

001의 표본 로드 확인을 전체 데이터 점검으로 확장함. 제공 파일을 읽을 수 있는지, 이미지·마스크의 크기와 전경값이 맞는지, 같은 원본의 파생 이미지가 한 분할에 모이는지 확인함. 원본 ID가 달라도 동일 이미지가 여러 분할에 들어갈 수 있으므로 파일 바이트와 디코드 RGB의 중복을 별도로 검사함.

분석 방법은 다음과 같음.

- AutoSplice 정상 파일은 품질별 목록에서 한 번만 등록함. 여러 조작본이 같은 마스크를 사용하는 관계는 허용함.
- 두 데이터셋의 이미지·마스크 폴더와 연결 목록을 대조해 누락·미참조 파일을 표시함. 고유 파일 전체를 디코드하고 모드·EXIF 방향·크기를 기록함.
- 마스크는 단일 채널, 값 0·255를 검사하고 공통 로더로 0/1 변환함. 빈 마스크와 전체 전경 마스크는 검토 대상으로 남김. 이미지·원본·마스크의 크기를 대조함.
- 연결 목록의 이미지에 대해 파일 SHA-256과 RGB 배열의 모양·자료형·픽셀을 포함한 SHA-256으로 정확한 중복을 검사함. 분할·데이터셋 교차, 다른 원본 ID, 정상/조작 라벨 또는 대응 마스크 차이를 표시함. 같은 원본·분할·라벨·마스크의 품질 변형은 따로 집계함. 미참조 파일은 중복 집계에서 제외하고 목록 차이로 별도 검토함.
- 크기·크롭 가능성은 AutoSplice train의 정상 원본과 JPEG100 조작본만 집계함. 조작 영역 비율은 조작 파일 단위와 고유 마스크 단위로 나눔.
- 크롭 후보 128·256·384·512는 두 변의 길이가 충분한지 비교하는 용도임. 학습 크기로 확정하지 않으며 조작 영역 포함 확률도 계산하지 않음.
- train JPEG100의 고유 마스크를 조작 영역 비율로 정렬해 순위 간격이 같은 최대 6개 표본을 표시함. 짧은 변이 작은 원본도 최대 3개 표시함. 원본·조작본·마스크·빨간 겹침 그림을 사람이 확인함.

AutoSplice test와 CocoGlide는 무결성·정확한 중복 검사에만 사용함. 테스트 분포나 성능으로 학습 설정을 선택하지 않음. 근접 중복은 이번 구현의 검사 범위에 포함하지 않으며, 정확한 중복 후보가 없다는 이유로 누수가 없다고 결론내리지 않음.

모델 구조·손실·최적화·체크포인트·평가 임계값은 해당 없음임. 크롭·리사이즈·ELA·JPEG 증강을 적용하지 않음.
