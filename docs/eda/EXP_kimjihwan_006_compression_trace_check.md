## 목적

seonghun 003은 파일 단위로 AutoSplice 정상 원본이 모두 Q75, JPEG100 조작본이 모두 Q100임을 확인했지만 이미지 안의 이중 압축 여부는 확인하지 않았음. 002~004 U-Net은 AutoSplice JPEG100에서 높고 JPEG90·75와 CocoGlide에서 무너졌음. 그 원인으로 세운 다음 가설을 모델 없이 손으로 만든 압축 지표로 측정함.

- **가설 A:** JPEG100 조작본의 마스크 밖은 Q75 원본을 Q100으로 다시 저장한 영역이라 Q75 양자화 흔적이 남고, 마스크 안은 새로 생성돼 그 흔적이 없음.
- **가설 B:** JPEG90·75 조작본은 이미지 전체가 다시 압축돼 그 차이가 약해지거나 사라짐.
- **가설 C:** CocoGlide에는 8×8 JPEG 격자 흔적이 없음.

추가 분석(8절)에서 CocoGlide가 마스크 안만 생성한 부분 편집인지 확인함. test split과 CocoGlide를 측정에 썼지만 모델 선택이나 설정 변경에는 쓰지 않음.

## 데이터

AutoSplice test 조작 JPEG 100·90·75 각 335장과 정상 원본(Q75) 228장, CocoGlide 정상·조작 각 512장. CocoGlide의 BAI·정렬도는 PNG 원본에서, ELA는 U-Net 평가 입력과 같은 JPEG100·4:4:4 변환본에서 측정함.

## 측정 지표

| 지표 | 정의 |
| --- | --- |
| Q75 격자 정렬도 | 디코더 휘도(Y, `draft`로 YCbCr 직접 출력)의 8×8 블록 DCT에서 저주파 AC 14개(u+v=1~4)를 표준 Q75 휘도 표로 나눈 값과 가장 가까운 정수의 거리 평균(0~0.5). 양자화 간격의 절반보다 작은 계수는 제외하고, 남은 계수가 3개 미만인 블록은 제외함. Q75로 저장된 적이 있으면 0에 가깝고 흔적이 없으면 약 0.25임 |
| 안·밖 구분 | 마스크에 완전히 들어간 블록(안)과 전혀 겹치지 않는 블록(밖). 경계 블록 제외 |
| AUC | 이미지마다 블록 지표로 안·밖 블록을 가르는 AUC(안이 클수록 높음)를 구해 평균. 안·밖 각 5블록 이상인 이미지만 계산 |
| ELA | 모델 입력과 같음(quality 90, scale 15, subsampling 2), 세 채널 평균 |
| BAI | 8의 배수 경계의 인접 픽셀 차이 ÷ 그 밖의 인접 차이. 1이면 격자 흔적 없음 |
| 전부 조작 기준선 | 모든 픽셀을 조작으로 예측했을 때의 이미지별 F1 평균 |
| 쌍 픽셀 차이(8절) | 같은 장면 정상본과 조작본의 RGB 절댓값 차이 평균. 밖은 마스크를 8픽셀 팽창한 영역의 바깥 |

## 분석

아래는 저장 출력에 대한 해석이며 팀 합의가 아님.

**가설 A 확인.** JPEG100 조작본은 335장 모두 마스크 밖의 Q75 흔적이 안보다 강하고, 안은 무작위 수준(0.25)임. 학습 없이 손으로 만든 지표 하나로 안·밖 블록을 AUC 0.92(정렬도)·0.94(ELA)로 가를 수 있음. 002~004가 JPEG100에서 F1 0.96~0.97을 낸 데 이 단서가 쓰였을 가능성이 높음. 단서가 존재함을 확인했을 뿐 모델이 실제로 썼는지는 이 측정으로 증명하지 않음(005·007·008에서 간접 확인).

**가설 B는 일부만 맞음.** JPEG90에서도 Q75 흔적의 안·밖 차이는 대부분 남음(AUC 0.886). 그러나 ELA에서는 값이 전체적으로 1/4 수준으로 작아지고 구분력이 약해짐(AUC 0.682). JPEG90에서의 붕괴는 정보가 사라져서라기보다, JPEG100에서 배운 형태의 단서가 다르게 보이기 때문일 수 있음. JPEG75에서는 이미지 전체가 Q75로 다시 정렬돼 정렬도 차이가 사라짐(AUC 0.489). JPEG75의 ELA AUC 0.723은 같은 품질 이중 압축의 차이이거나 생성 영역의 질감 차이일 수 있으며 이 측정으로는 구분하지 못함.

**가설 C 확인.** CocoGlide PNG에는 정렬된 8×8 JPEG 격자 흔적이 없음(BAI 약 1.00, 정렬도 0.256). 004 보고서의 추론을 측정으로 확인함. 또 CocoGlide는 이미지 전체의 ELA 평균(약 48)이 AutoSplice 조작 영역(31.8)보다 높고 마스크 안·밖 차이가 없음. "ELA가 높으면 조작"을 배운 모델이 CocoGlide를 통째로 칠한 결과(정상 오탐률 0.94~0.98)와 맞음. 002~004의 CocoGlide F1(0.359~0.361)은 전부 조작 기준선 0.355와 거의 같음.

**CocoGlide는 부분 편집임.** 마스크 밖 픽셀이 원본과 사실상 같음(차이 최대 1.0, 8 초과 0%). CocoGlide 위치 검출은 압축 흔적이 아니라 "실제 사진 속 생성 영역"을 찾는 문제로 성립함.

## 한계

- CocoGlide ELA는 팀 기준 변환(JPEG100·4:4:4)에서 쟀고 ELA는 4:2:0으로 재압축하므로 색차 서브샘플링 오차가 더해졌을 수 있음. 4:2:0 변환본은 측정하지 않음.
- BAI는 원점에 맞춘 8×8 격자만 봄. 크기 조정 등으로 간격이 바뀐 흔적은 측정하지 않음.
- test split만 측정함. 작은 마스크는 경계 블록 제외로 블록 수가 적음.
- 5·6절의 이미지별 CSV는 Drive 용량 초과 기간에 저장돼 Drive에 남지 않았을 수 있음. 표 값은 노트북 출력에서 옮김.
